YuvaIntern Task 6 – Final Project and Assessment

Capstone project: Student Internship & Placement Management System. This full-stack web application was selected from existing internship work and improved into a complete, presentation-ready capstone. It helps students discover internship and placement opportunities, submit structured applications, track application status over time, and manage skills and resumes, while giving administrators a controlled back-office to publish listings, review applicants, and export reports.

Key features include secure registration and login with hashed passwords, role-based access for students and administrators, searchable and filterable opportunity listings, application submission with a minimum cover-letter length, duplicate-application blocking at both the UI and database level, a five-state application workflow (Applied, Under Review, Shortlisted, Selected, Rejected) with an auditable history, a personal dashboard with counts, deadlines and recent activity, profile and skills management, a printable resume view, strictly validated resume uploads, admin user and listing management, aggregate statistics, and filtered CSV export.

The technology stack is Python 3.14, Flask 3.1, SQLite, HTML5, CSS3, vanilla JavaScript, and pytest. The application uses parameterised SQL queries, per-session CSRF tokens, login and admin route decorators, per-record ownership checks, server-side validation, safe error pages, and secure file uploads. It is documented with architecture and testing guides, setup instructions, and deployment notes.

Quality was verified with 59 automated pytest cases across test_app.py and test_edge.py, all passing in approximately 75 seconds, plus an idempotent seed script. The Word report documents the specification, architecture, features, testing, security, limitations, and a presentation checklist. Manual actions remaining are GitHub repository creation and push, and optional Vercel deployment; no public submission or push was performed without approval.
